# Angular E-commerce

Projeto acadêmico desenvolvido com Angular para representar a interface de um sistema de e-commerce.

## Atividades de diretivas

Os exercícios de diretivas e controle de fluxo do Angular estão isolados na branch `atividade-diretivas`. Essa separação mantém o código das atividades fora da estrutura principal do e-commerce.

Para acessar as atividades:

```bash
git switch atividade-diretivas
```

Para retornar ao projeto principal:

```bash
git switch main
```

## Executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm start
```

A aplicação ficará disponível em `http://localhost:4200`.
